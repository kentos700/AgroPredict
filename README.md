# AgroPredict — прогнозирование урожайности методами машинного обучения

## 1. Описание проекта

**AgroPredict** — учебный дипломный проект на Python и Flask, который демонстрирует применение методов машинного обучения для повышения эффективности прогнозирования урожайности сельскохозяйственных культур.

Система принимает аграрные, климатические и почвенные параметры участка, формирует одну строку данных в формате `pandas DataFrame`, передает ее в обученный `scikit-learn Pipeline` и возвращает прогноз урожайности в тоннах на гектар.

Проект подходит для курсовой или дипломной работы: в нем есть веб-интерфейс, база данных, ML-pipeline, визуализация метрик и понятная структура кода.

## 2. Возможности системы

- ввод параметров региона, культуры, сезона, климата, почвы и агротехники;
- валидация формы на стороне Flask;
- прогнозирование урожайности с помощью обученной ML-модели;
- сохранение каждого прогноза в SQLite;
- просмотр истории прогнозов от новых к старым;
- dashboard с метриками моделей и графиками;
- обработка ошибок: отсутствующая модель, некорректные данные, ошибки чтения CSV и базы данных;
- современный адаптивный интерфейс на Bootstrap 5.

## 4. Установка зависимостей

Перейдите в папку проекта:

```bash
cd crop_yield_prediction
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 5. Инициализация базы данных

Для создания SQLite базы данных выполните:

```bash
python init_db.py
```

После выполнения появится файл:

```text
instance/app.db
```

## 6. Обучение модели

Для обучения моделей и генерации артефактов выполните:

```bash
python ml/train_model.py
```

Скрипт выполняет:

1. чтение `data/crop_yield.csv`;
2. проверку обязательных столбцов;
3. разделение данных на признаки `X` и целевую переменную `Yield`;
4. предобработку числовых и категориальных признаков;
5. обучение трех моделей;
6. расчет метрик;
7. выбор лучшей модели по `R2` и `RMSE`;
8. сохранение модели в `ml/model.pkl`;
9. сохранение метрик в `ml/metrics.json`;
10. генерацию графиков `model_comparison.png` и `feature_importance.png`.

## 7. Запуск приложения

После создания базы данных и обучения модели запустите Flask:

```bash
python run.py
```

Откройте приложение в браузере:

```text
http://127.0.0.1:5000
```

## 8. Используемые алгоритмы машинного обучения

В проекте обучаются три регрессионные модели:

### LinearRegression

Линейная регрессия используется как базовая интерпретируемая модель. Она хорошо показывает простой линейный ориентир качества.

### RandomForestRegressor

Случайный лес строит ансамбль деревьев решений и хорошо работает с нелинейными зависимостями. Модель устойчива к шуму и обычно показывает сильное качество на табличных данных.

### GradientBoostingRegressor

Градиентный бустинг последовательно строит деревья, каждое из которых исправляет ошибки предыдущих. Часто дает высокую точность на задачах регрессии.

## 9. Метрики оценки

Для каждой модели рассчитываются:

- **MAE** — средняя абсолютная ошибка;
- **MSE** — средняя квадратичная ошибка;
- **RMSE** — корень из средней квадратичной ошибки;
- **R2** — коэффициент детерминации.

Лучшая модель выбирается по правилу:

1. максимальное значение `R2`;
2. при равенстве — минимальное значение `RMSE`.
